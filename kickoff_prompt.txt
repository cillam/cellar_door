4. Implement `app/routers/items.py` — six endpoints per SPEC.md:
     - POST /items/from-photo: starts graph, streams SSE through
       await_category, then closes (interrupt reached). Verifies that
       storage_path starts with photos/<user_id>/ — see SPEC.md Auth.
     - POST /items/from-photo/{thread_id}/resume: resumes graph via
       Command(resume=category). Checks graph state user_id matches JWT
       user_id (403 on mismatch). Handles 410 on expired checkpoints and
       409 on already-resumed graphs.
     - POST /items: saves a complete Item payload. Server assigns id and
       user_id; client-provided values are ignored.
     - GET /items: user-scoped inventory list.
     - GET /items/{id}: single item, user-scoped.
     - PATCH /items/{id}: partial update. Enforces the immutable-field
       list from SPEC.md (id, user_id, category, photo_url, created_at,
       confidence_scores → 400 on change attempts).
     - DELETE /items/{id}: 204 on success, 404 on missing or cross-user.
       Also deletes the photo from Supabase Storage.

   parse the bearer token; real JWKS verification comes in step 5).
   Integration tests with testcontainers-postgres.
